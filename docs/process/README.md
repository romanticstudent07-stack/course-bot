# Процесс v2 «Синергия» — как делаем course-bot

Принят 27.09.2026. Цель: всё до итерации 6 + переезд на VPS (0-Б) за 1–2 месяца.
Думают и пишут код бесплатные чаты Claude Opus 5.5 (Genspark AI Chat).
Тесты — Codespaces (быстрые) и CI (все, включая БД). Платный агент — исключения
и важные задачи на свободный остаток кредитов.

## Роли (все чаты — Opus 5.5)
- Автор: вставляет пакеты, запускает команды, открывает и мержит PR, принимает
  архитектурные и денежные решения.
- ШТАБ: чат-наставник (промпт у Автора, AGENT-CHAT-CONTEXT.txt). Процесс, очередь,
  решения между задачами, учёт, разбор нестандартных проблем.
- ПРОЕКТИРОВЩИК (docs/process/DESIGNER.md): новый чат на пачку 3–5 карточек задач.
- КОДЕР (docs/process/CODER.md): новый чат на КАЖДУЮ задачу.
- СЕРВЕРНЫЙ (docs/process/SERVER.md): один чат на 3–4 задачи, только IRONCLAD.
- Codespaces: раскладка пакета (tools/unpack.py) и быстрые тесты (tools/check.sh).
- CI: 7 проверок на каждый PR, тесты с БД. Главный тестировщик.
- Агент Genspark (кредиты): режимы Р1-П и Р1.

## Лестница способов (от дешёвого к дорогому)
- Р0 «Сайт»: 1–3 файла без логики, .github/** → сайт GitHub или github.dev. 0 кредитов.
- Р0+ «Пакет» (ОСНОВНОЙ): КОДЕР пишет пакет → Codespaces: unpack → check → push → PR → CI.
- Р1-П «Агент-раскладчик»: тот же пакет + короткий промпт агенту (AGENT-BRIEF.md, раздел 11).
  Когда: пакет больше 12 файлов; 2 круга красного CI без понятной причины; у Автора нет времени.
- Р1 «Агент-исполнитель»: только если задачу нельзя описать карточкой.
- Запасной: кончилась квота Codespaces → Р0 через github.dev (до 6 файлов) + CI.

## Правило «не больше 4 запросов в чате»
- Из-за сжатия истории чат живёт не больше 4 запросов Автора, потом — новый чат.
- Каждый ответ любого чата заканчивается блоком ПЕРЕДАЧА (до 8 строк). Новый чат
  стартует с этого блока — ничего не теряется.
- Тяжёлые запросы (пакеты) — в начале 5-часового окна лимита. Лимит кончился →
  Автор делает ручную часть (Codespaces, сервер, мерж), не ждёт.

## Память проекта (в репо, читается чатами по ссылкам)
- docs/STATE.md — состояние. docs/tasks/<id>.md — карточки задач.
- docs/process/*.md — правила чатов. AGENT-BRIEF.md — факты и запреты проекта.
- Чтение: https://raw.githubusercontent.com/romanticstudent07-stack/course-bot/main/<путь>
  → не открылось: https://api.github.com/repos/romanticstudent07-stack/course-bot/contents/<путь>?ref=main
  → не открылось: попросить Автора вставить файл. По памяти не восстанавливать.

## Размеры
- Одна задача = один PR: до 12 файлов и примерно до 600 строк кода. Больше — две задачи.
- Задачи с миграциями БД не объединять. Мелочи без БД — объединять.
- Миграция добавляет таблицы → в карточке ручная правка ci.yml (число таблиц) режимом Р0.

## Кредиты
- Тариф Plus 10 000/мес, остаток сгорает. Резерв 1 500. После 20-го числа свободный
  остаток — агенту на важные задачи (решает ШТАБ с Автором).
- Учёт каждой задачи: режим / оценка / факт / часы Автора — в docs/STATE.md.

## Публичный репо
- Считаем, что всё в нём публично навсегда. Никаких реальных Telegram ID, IP, имён хостов, ПДн.
- Secret scanning + Push protection включены. Логи CI видны всем — env не печатать.

## Стоп-правила
- Одна и та же ошибка 2 раза → третья попытка последняя → дальше Р1-П или ШТАБ.
- unpack отклонил пакет → текст ошибки назад в КОДЕР, скрипт не обходить.
- Красный CI и вопросы без ответа — не мержим. Сервер — только main.
