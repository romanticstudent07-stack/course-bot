# БЛОК 8. РАБОЧАЯ ГРУППА

> **Уточнено ERRATA-UNIFIED.** Привязки тем (`topic_bindings`), зеркало админ-темы с write-ahead-записью и двойной сверкой, режим паники `/panic_maintenance` — патч И4. В п. 8.4 из reply-команд удалён `/place` — команда упразднена поправкой v3.1. См. [normative/I4-wave-d.md](normative/I4-wave-d.md), [12-reserve.md](12-reserve.md).

## 8.1. Принцип «больше папок»

Каждая сущность — в своей теме, никакой мешанины. Рабочая группа — это пульт управления Автора/Помощников. Участники сюда доступа не имеют.

## 8.2. Структура тем

**Рефлексии** — очередь на проверку (дни 6 / 13-M / 13-P). Кнопки: Одобрить проход / Вернуть /revert / Карточка / Написать.

**Отчёты и активность** — отчёты, «всё не выполнено», несдача, полуденная неактивность, «пришёл, но не отправил» (день 2). Кнопки: Карточка / Написать.

**Оплаты** — подтверждения платежей (чеки не автоудаляются). Кнопки: Подтвердить / Отклонить / Карточка / (под подтверждённым чеком) Рефанд.

**Паузы** — запросы, авто-паузы (по молчанию Автора), доп.паузы. Кнопки: Одобрить / Отклонить / Доп.пауза / Карточка.

**Карточки** — вызванные карточки (одна на участника, автоочистка 24ч).

**Поддержка** — обращения участников + кнопка поддержки из онбординга. Кнопки: Карточка / Написать.

**Тревожная динамика** — Чек-Ап без улучшения / с ухудшением.

**Сводки/Система** — утренняя сводка 09:00 (по ТЗ Автора, с пометкой типа рефлексии Чек/Переход/Рубеж и датой), системные уведомления.

**График** — точный расчёт на 7/14 дней (новый график → удаление старого).

## 8.3. Два канала (карта взаимодействий)

**Личный чат (Бот ↔ Участник)** — задания, кнопки, отчёты, рефлексии, уведомления, пересланные ответы Автора. Участник не видит «кухню».

**Рабочая группа (Автор/Помощники + Бот)** — пульт. Сюда Бот постит отчёты, рефлексии (6 / 13-M / 13-P), алерты (несдача, «всё не выполнено», оплата, запрос паузы, N-й возврат на закрепление), утреннюю сводку, график.

## 8.4. Команды в группе

Автор даёт команды в Рабочей группе через reply на конкретное сообщение Бота (reply нужен для привязки к Участнику по user_id). Гибрид (Вариант 3): кнопки для частых простых действий (Approve, +жизнь, Пауза) + reply-команды для параметрических/редких (`/revert 2.8`). Детали команд — в Блоке 17. _(Пример `/place 1.5` удалён поправкой v3.1 — команда `/place` больше не существует.)_

## 8.5. Кликабельное имя Участника

Во ВСЕХ сообщениях Бота в Рабочую группу (отчёт, рефлексия, алерт, оплата, пауза) — кликабельная ссылка на Участника через числовой user_id: tg://user?id=… (username ненадёжен). Формат: Имя (@username · ID 12345) → [написать]; если username нет — просто кликабельное имя.

## 8.6. Технические требования к боту в группе (подтверждено ресёрчем)

**Права администратора.** Бот должен быть администратором группы с правом can_delete_messages (для автоочистки карточек, замены графика; удаление своих сообщений — без ограничения по времени, чужих — лимит платформы ~48ч).

**Маршрутизация по темам.** Callback-роутинг по message_thread_id — Бот определяет, из какой темы (форум-топика) пришло нажатие, и маршрутизирует действие соответственно. Отправка сообщений в конкретную тему — через message_thread_id.

**Кнопки в топиках.** Inline-кнопки работают внутри форум-топиков группы; callback-запросы идентифицируются и привязываются к participant_id.

## 8.7. Поток на примере дня 13

1. Участник в личном чате сдаёт отчёт + рефлексию дня 13.
2. Бот проверяет задания дня → статус «ждёт проверки Автора» (вердикт pending в БД).
3. Бот постит рефлексию в тему «Рефлексии» с кликабельным именем + кнопки [Одобрить проход] / [Вернуть /revert].
4. Автор нажимает кнопку (или reply + команда).
5. Бот записывает вердикт в БД и пересылает текстовый ответ Автора Участнику в личный чат. Применение вердикта — на переходе Дня 14 (Блок 7.7). Если Автор молчит до порога 21:00 ТЗ Участника — включается тайная пауза (Блок 7.7, фаза C), авто-прохода нет.

## 8.8. Связь «Написать участнику через Бота»

Кнопка ✉️ под релевантными сообщениями: Автор пишет текст в группе → Бот доставляет Участнику от имени Бота (Автор не выходит из рабочего контекста, Участник не видит «кухню»).

## 🛡 Блок 8 — Fail-safe

Команда без reply (Бот не знает, о ком речь) → Бот не выполняет, просит reply. Whitelist admin-ID: команды принимаются только от лиц в whitelist; команда от не-в-whitelist → игнор + лог. Callback строго привязан к participant_id (действие под сообщением X адресует именно X). Бот-администратор с can_delete_messages — обязательное требование, иначе автоочистка карточек и замена графика не работают (проверять при старте). Кликабельное имя всегда через числовой user_id, не username. Чеки в теме «Оплаты» не автоудаляются; карточки — автоудаление 24ч; график — замена предыдущего.

## YAML — рабочая группа (Блок 8)

```yaml
# ============================================================
# БЛОК 8 — Рабочая группа
# Версия: consolidated v3
# ============================================================

working_group:
  purpose: control_panel                  # пульт Автора/Помощников; участникам закрыт
  principle: "больше папок — каждая сущность в своей теме"

  bot_requirements:
    admin_rights: true
    can_delete_messages: true             # автоочистка карточек, замена графика
    own_messages_delete: unlimited_time
    others_messages_delete: platform_limit_48h
  callback_routing: by_message_thread_id  # бот знает тему нажатия
  send_to_topic: via_message_thread_id
  inline_buttons_in_topics: supported     # подтверждено ресёрчем

  topics:
    reflections:
      content: "очередь дни 6 / 13-M / 13-P"
      buttons: [approve_pass, revert, card, write]
    reports:
      content: ["отчёты", "всё не выполнено", "несдача", "полуденная неактивность", "пришёл-не-отправил day2"]
      buttons: [card, write]
    payments:
      content: "подтверждения платежей"
      cheques: never_auto_delete
      buttons: [confirm_payment, reject_payment, card, refund_under_confirmed]
    pauses:
      content: ["запросы", "авто-паузы по молчанию", "доп.паузы"]
      buttons: [approve, reject, pause_extra, card]
    cards:
      content: "вызванные карточки"
      one_per_participant: true
      auto_delete: 24h
    support:
      content: ["обращения участников", "кнопка поддержки из онбординга"]
      buttons: [card, write]
    dynamics:
      content: "Чек-Ап без улучшения / с ухудшением"
    summaries:
      content: ["утренняя сводка 09:00 ТЗ Автора", "системные уведомления"]
    graph:
      content: "точный расчёт 7/14 дней"
      on_new: delete_previous               # хранит last_graph_message_id

  channels:
    personal_chat: "Бот↔Участник: задания, кнопки, отчёты, рефлексии, уведомления, ответы Автора"
    working_group: "Автор/Помощники+Бот: отчёты, рефлексии, алерты, сводка, график"

  commands_in_group:
    binding: reply_to_bot_message           # reply -> user_id
    model: hybrid_variant_3                  # кнопки (частое) + reply-команды (редкое/параметрическое)
    detail: block_17

  clickable_name:
    method: "tg://user?id=…"                # числовой id, username ненадёжен
    format: "Имя (@username · ID 12345) → [написать]"
    fallback: clickable_name_only

  write_via_bot:
    flow: "Автор пишет в группе -> Бот доставляет участнику от имени Бота"

  failsafe:
    command_without_reply: [do_not_execute, ask_for_reply]
    whitelist_only: true
    non_whitelist_command: [ignore, log]
    callback_bound_to: participant_id
    require_bot_admin_on_start: true
```
