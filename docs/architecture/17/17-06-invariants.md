## Сквозной инвариант блока: бот никогда не банит (NR-17.14)

Автомат не может забанить участника: перевод в `banned_soft`/`banned_hard` доступен **только** через явную команду Автора/Помощника (`/block`) с двухшагом и записью инициатора. Автопроцессы (лимиты, антипираттство, аномалии, нарушения) переводят участника в `sleeping`/`erased`/`muted`, но никогда — в `banned_*`. Маршрутизатор жёстко отсекает попытки автопродуктов запросить `banned_*`-переход. Матрицы Б17 отражают только допустимый ручной путь: `/block` из `active` и `sleeping` — OK; из `owner_paused` — OK; из `banned_soft` в `banned_hard` — OK (эскалация внутри бана); все обратные пути — по `/unblock`. Любые «сделать бан навсегда» кроме ручного `/block hard` — отклоняются.

## NR-инварианты Б17

- **NR-17.1** — Кнопки Карточки одного пути с командой — идентичны по контракту (диалог/двухшаг/идемпотентность); визуальные ярлыки — параллельный слой доступа, а не альтернативный маршрут.
- **NR-17.2** — В команде и в кнопке фактический `participant_id` берётся из reply-target, никаких «текущего диалога» — не бывает.
- **NR-17.3** — Помощник = член whitelist; никаких DM Автору вне рабочей группы для этих ролей.
- **NR-17.4** — Все команды идемпотентны по operation_key: `hash(actor,cmd,participant,argset)`, повтор возвращает первый результат.
- **NR-17.5** — `/place` не восстанавливается ни при каких условиях; попытка — аудит, а не исполнение.
- **NR-17.6** — Двухшаг обязателен для всего необратимого (`/refund`, `/refund_rollback`, `/block`, `/unblock`, `/erasure_*`, `/panic_maintenance`, `/unpanic`, `/revert` при рисках, `/publish_stage`, `/withdraw_stage`, `/whitelist_change`, `/bind_topic`, `/unfreeze_piracy`, `/dlq_replay`).
- **NR-17.7** — Кнопка «Да» на подтверждении не занимает место первой кнопки (защита от «пальца»).
- **NR-17.8** — Кнопки не доступной роли не рендерятся вовсе (нельзя тапнуть).
- **NR-17.9** — Callback несёт `schema_version` и `nonce`; устаревшие/чужие — no-op.
- **NR-17.10** — `/legal` доступен только по прямой кнопке-ярлыку `📎 Legal`; попытка вызова командой без ярлыка — no-op с аудитом.
- **NR-17.11** — Тайм-аут мастера параметров 10 минут; один активный мастер на `{actor, cmd, participant}`.
- **NR-17.12** — `expected_*` в мастере (state, lives, photo_hash, publish_epoch) обязателен для критики; несовпадение — отказ с диагнозом.
- **NR-17.13** — Экспорт `/audit` в CSV запрещён.
- **NR-17.14** — Бот никогда не банит автоматически (см. отдельный раздел выше).
