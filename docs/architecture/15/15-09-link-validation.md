# БЛОК 15 · ШАГ 9 — ВАЛИДАЦИЯ ССЫЛОК

Автоматическая проверка «жив ли конкретный пост канала» исключена сознательно по двум причинам: платформенная (легитимный бот не может читать сообщения канала, не будучи его администратором; метода проверить чужой пост через Bot API нет) и организационная (владелец свежести ссылок — Автор, гарантирующий валидность ссылок в конфиге). Бот отдаёт ссылки ровно как в конфиге и не перепроверяет их существование. Это не пробел, а граница ответственности.

Что остаётся — валидация формата при загрузке конфига: при старте и перечитывании бот проверяет, что каждое поле-ссылка синтаксически корректно (не пустое, не плейсхолдер TODO/«—»/пробелы, похоже на ссылку по форме). Чисто строковая проверка, сеть не задействуется. Назначение — поймать опечатку/обрыв строки до того, как участник получит дыру вместо ссылки (исполнение «нет пустых экранов»: дефект ловится на входе). При провале формат-валидации бот не падает: логирует проблему (стык с Шагом 8), сигнализирует Автору о конкретном месте (stage/day, поле), применяет безопасный фоллбэк для участника (задание без сломанного элемента или с нейтральной пометкой, экран никогда не пуст). Дефект одной ссылки не блокирует выдачу всего задания и не прерывает бота.

Явно НЕ входит: регулярный фоновый чекер (нет надёжного сигнала в Bot API, массовый HTTP-обход t.me упирается в непредсказуемые flood-лимиты); HTTP-пинг t.me и трактовка кодов как признака мёртвого поста (шумно, ложные 403/405/таймаут прячут живой контент); UX-фоллбэк при невозможности участника открыть валидную ссылку (транспорт/навигация — передан в Блок 10).

## YAML — Шаг 9

```yaml
block_15:

  # ================================================================
  step_9:
    title: "Валидация ссылок"
    status: closed
    post_liveness_check:
      enabled: false
      reason: ["Bot API не читает чужой канал без прав админа", "Автор владеет свежестью; ссылки в конфиге гарантированы"]
      background_checker: none
      http_ping_tme: none
      freshness_owner: author
    format_validation:
      when: [config_load_on_start, config_reload]
      network: false
      checks: ["не пустое", "не плейсхолдер (TODO/dash/whitespace)", "синтаксически похоже на ссылку"]
      purpose: "поймать опечатку/обрыв до того, как участник увидит дыру"
      invariant: no_empty_screens
    on_format_failure: {crash: false, author_signal: "точное место (stage/day, поле)", log: "-> Step 8", participant_fallback: "задание без сломанного элемента / нейтральная пометка; экран не пуст", scope_guard: "одна ссылка не блокирует всё задание/бота"}
    out_of_scope: ["периодический фоновый чекер", "t.me HTTP ping / трактовка кодов", "клиентская невозможность открыть валидную ссылку -> Block 10"]
```
