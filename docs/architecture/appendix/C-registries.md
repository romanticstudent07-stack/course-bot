# ПРИЛОЖЕНИЕ C. РЕЕСТРЫ

Это производный реестр: ступени старшинства не имеет, при расхождении с файлом-источником побеждает источник. Источники истины перечислены в шапке каждого раздела.

## 1. Парковка (блоки к разбору) — редакция v3.1

Строка «Блок 12 — Миграция…» удалена поправкой v3.1 (см. [12-reserve.md](../12-reserve.md), п. 12.4). Из строки блока 17 удалено упоминание `/place`.

**Блок 9 — Коммуникации / Уведомления:** состав экрана настроек с чекбоксами (что отключаемо), 3-тир система (системные / напоминания / мотивационные), тексты алертов.

**Блок 10 — Жизненный цикл участника и возвращение:** состояния (активный / спящий / архив / блок / ждёт оплаты), логика кнопки [Старт], матрица доступности кнопок по состоянию. **Закрыт** — см. [10-lifecycle-return.md](../10-lifecycle-return.md) и подпапку [10/](../10/).

**Блок 13 — Доступ к пройденному материалу** / режим самостоятельного повторения. **Закрыт** (v2.1) — см. [13-past-material-access.md](../13-past-material-access.md).

**Блок 14 — Данные, Карта изменений, замеры, durability** (WAL, бэкапы 3-2-1, PITR), ТЗ-сбор, финишная точка (её отсутствие), уведомление о новых модулях, слои Карты изменений (антропометрия / фото 4 стороны / самочувствие / функциональные), повторные опросы после каждого Этапа. **Закрыт** (v3.4) — см. [14-data-durability.md](../14-data-durability.md).

**Блок 15 — Хранение и доставка контента** (в т.ч. «контент в закрытом ТГ-канале»), анти-пиратство, водяные знаки. **Закрыт** — см. [15-content-antipiracy.md](../15-content-antipiracy.md) и [15/](../15/).

**Блок 17 — Панель Автора / командный режим («доступ Бога»):** revert, life, pause_grant, approve, зачисление оплаты, `/refund`, `/card`, `/legal`, ✉️ написать участнику; все командные кнопки; аудит-лог доступа к карточкам. **Закрыт** — см. [17-author-panel.md](../17-author-panel.md) + патч [normative/B17-admin-panel-patch.md](../normative/B17-admin-panel-patch.md).

**Юридический блок** — 54-ФЗ, самозанятость (лимит 2,4 млн ₽/год), возвраты, мед.дисклеймеры/скрининг, текст красной зоны Чек-Апа, GDPR/152-ФЗ (данные о здоровье — спец.категория), возврат несовершеннолетним/передумавшим после оплаты. **Закрыт** (v1 + ПАТЧ v2 + v2-ext-r) — см. [99-legal.md](../99-legal.md) и [99/](../99/).

## 5. Реестр команд бота

Источник: `Б17.command_registry`. **Каноническое число — 35 команд** (пересчёт по каталогу: 8+6+3+6+3+9 = 35). Сам патч Б17 в двух местах (`stub_closure.closed_by_this_patch` и заголовок RISK-L-22 «25-command dict») говорит 25 — расхождение зафиксировано долгом (RISK-L-22, см. выше). Команда `/grant_photos_access` упомянута в примечании к `/view_photos`, но собственной записи в каталоге не имеет — висячая 36-я команда, требует решения Автора.

### 5.1. Жизненный цикл (8)

`/start`, `/pause_author`, `/unpause_author`, `/block`*, `/unblock`*, `/life`, `/erasure_initiate`, `/erasure_finalize_before_cooling_off`†

_(*)_ команды `/block` и `/unblock` управляют носителем состояния, которого нет: `banned_soft`/`banned_hard` удалены Р477 (И2). Решение Автора не принято — см. `open_incompatibilities` в [normative/README.md](../normative/README.md).
_(†)_ противоречит отсрочке стирания И3 (14 дн. при активном возврате). До решения Автора действует И3.

### 5.2. Данные (6)

`/card`, `/export`, `/view_photos`, `/override_baseline`, `/publish_stage`, `/audit`

_(Про `/grant_photos_access` — см. висячая 36-я, выше.)_

### 5.3. Финансы (3)

`/refund`, `/refund_rollback`, `/reconcile_psp`

### 5.4. Модерация и группа (6)

`/approve`, `/revert`, `/panic_maintenance`, `/graph`, `/graph_review`, `/announce`

### 5.5. Правовое (3)

`/legal`, `/consent_export`, `/privacy_report`

### 5.6. Служебное (9)

**Оговорка о самопротиворечии `command_palette`.** В `command_palette.note` записано `search queries hashed`, а в `command_palette_amendments` — `search_queries_storage: plaintext`. Правило приоритета внутри Б17: **при расхождении внутри одного файла секции `*_amendments` старше первой половины файла** — RISK-L-22 CLOSED в этой редакции по amendments.

## 6. Сводный реестр инвариантов и CI-чеков

Источник: `И1.invariants_final`, `И2/И4.ci_checks_*`, `Б99.invariants_final`, `debt/*/INV-*`.

### 6.1. Инварианты уровня стека

- **I-1** — `participant_state`: единственный писатель — `participant_state_projector` (И1, подтверждён E1 ERRATA).
- **I-2** — `publish_epoch`: владелец — блок 14 (И1 → FIX1 ERRATA).
- **I-3** — идемпотентность всех command-buttons на UI-слое (И1).
- **I-4** — запрет свободного текста в enum-полях причин (И1).
- **I-5** — `outbox` компакция: `INV-OUTBOX-SENT-AT-COMPACTION` (И2 + ADD1 ERRATA).
- **I-6** — non-reidentifiability после стирания (И1 + A4).

### 6.2. Продуктовые инварианты

- **П-21** — «нет пустых экранов» ни в одном состоянии.
- **П-31** — зачёт дня только по подтверждённой записи в БД.
- **INV-AGE-GATE-BEFORE-PID** — `pid` не создаётся до жёсткой проверки возраста (ADD3 ERRATA).
- **NR-17.1…23** — non-regression по блоку 17 (v3.4).

### 6.3. Юридические инварианты (действующие)

INV-L-04, 05, 07, 12 — считаются действующими до решения Автора (перечислены в [99-legal.md](../99-legal.md), «Открытый вопрос по инвариантам»).

### 6.4. Технические инварианты debt/

- **INV-A3-COMPACTION** — компакция outbox с `sent_at` (`debt/15-A3-*`).
- **INV-A4-BACKUP-ERASURE** — стирание всех версий объектов + учёт WAL (`debt/15-A4-*`).
- **INV-B14-*** — durability WAL/backup Блока 14.
- **INV-C4-MAINT** — контракт maintenance C4 (`debt/infra-C4-maintenance-contract.md`).

### 6.5. Сводный счёт CI-чеков

Декларировано в стеке: 40 из И1–И4 + 10 из Б17 = **50+ CI-чеков**. Фактический сводный список формируется отдельно (см. раздел 9 ниже — «Долги реестра»). До завершения сборки этого списка Автор не может настроить полный пайплайн.

## 8. Boot-gate — что блокирует прод-запуск

Источник: `errata-unified.final_state.blocking_prod_launch`. Более развёрнутый список, чем краткий в [normative/README.md](../normative/README.md), «Общий шлюз».

1. Каждый обязательный клиентский текст помечен `verified_by: legal_block` (12 текстов из юрблока + Д-25…Д-28 + F1 + `red_flags_emergency_text` + Ш21 из И3 + возвратный контур + тело красной зоны + Д-27 + Д-28 + F2 + R381 из И4 + `A3 psp_erasure_disclosure` из ERRATA — по факту 15+ текстов на `pre-legal-review`).
2. Д-40 закрыт (РКН-уведомление реальным событием).
3. Д-30 закрыт (DPA с провайдером).
4. Д-31 закрыт (модель угроз, УЗ-3).
5. `{s3-domain-ru}` / `{s3-domain}` заменён на реальный домен (унифицирован ERRATA раздел 6).
6. `full_backup_rotation_cycle` заменён на реальное число (ADD5, NOTE2, при подстановке брать более строгую границу A4 с учётом WAL).
7. Все `legal_status: pre-legal-review` сняты после юридической вычитки.

## 9. Долги реестра (что ещё в сборке)

- **Сводный CI-список.** Итоговый плоский список всех 50+ CI-чеков с id/пойнтером/владельцем — задел под `build/ci-checks.yaml`, см. раздел VI финального отчёта.
- **Тексты `pre-legal-review`.** Плоский список 15+ id из `text_registry` для отправки юристу — задел под `build/config/text_registry_pre_legal_review.yaml`.
- **RISK-L-22 (25 vs 35 команд).** Решение Автора о канонизации числа команд.
- **Висячая 36-я команда `/grant_photos_access`** — либо завести полную запись в каталоге Б17, либо убрать примечание в `/view_photos`.
- **Роли `finance` и `moderator`.** Не определены в глоссарии, но используются в матрице прав Б17. Задел — расширить [00-glossary.md](../00-glossary.md) после решения Автора.
- **Три несовместимости Б17.** См. `open_incompatibilities` в [normative/README.md](../normative/README.md).
