# ПРИЛОЖЕНИЯ К ЗАКРЫТОЙ ЧАСТИ

Это сквозные конструкции, не привязанные к одному блоку: глобальные правила (Патч-1), сводный Реестр Fail-safe и Реестры парковки / открытых вопросов / blind spots.

| Приложение | Содержание | Файл |
|---|---|---|
| A | Патч-1 — сквозные глобальные правила (P1–P6) | [A-patch1-global-rules.md](A-patch1-global-rules.md) |
| B | Сводный реестр Fail-safe | [B-failsafe-registry.md](B-failsafe-registry.md) |
| C | Реестры: парковка, открытые вопросы, blind spots | [C-registries.md](C-registries.md) |

Единый YAML приложений («YAML — сквозные правила») содержит две секции: patch_1_global и failsafe_registry. В оригинале он расположен после Приложения C; в нарезке хранится целиком и без изменений в Приложении A, приложения B и C ссылаются на него.
