# ПРИЛОЖЕНИЕ A. ПАТЧ-1 — СКВОЗНЫЕ ГЛОБАЛЬНЫЕ ПРАВИЛА (P1–P5)

> **Уточнено поправкой v3.1.** Пункт **P-6** (команда `/place`) удалён целиком. Нумерация P-1…P-5 сохраняется, чтобы не ломать возможные ссылки; P-6 просто исчезает как пункт. Из YAML `patch_1_global` удалён ключ `P6_place_command`. См. [12-reserve.md](../12-reserve.md), п. 12.4.

## P-1. Инвариант нумерации модулей

Жёсткое правило системы: нумерация модулей глобально сквозная и уникальная (1, 2, 3, 4, 5…). Запрещено «модуль 1 внутри этапа 2». От этого инварианта зависят: парсинг команды `/revert Модуль.День`, вычисление Этапа из номера модуля, адресация в командах. Нарушение инварианта ломает адресацию — валидируется на уровне конфигурации.

## P-2. Часовой пояс Автора

У Автора есть собственный ТЗ (тайм-зона), задаётся в конфигурации. Все «авторские» тайминги считаются по ТЗ Автора, в частности утренняя сводка — 09:00 по ТЗ Автора, и график (по ТЗ Автора). Все прочие контрольные точки времени — по ТЗ Участника.

## P-3. Тихий ночной режим Автора — ОТМЕНЁН

Ночной режим не используется (решение Ф-25 / Н-2). Боту тихий режим не нужен — участники сами настраивают уведомления средствами Telegram, а Бот учитывает ТЗ каждого участника. Алерты Автору приходят без искусственной ночной буферизации; управление тишиной — на стороне Автора вне бота. (Это отменяет ранние формулировки П-2/П-3 из черновиков, где ночной режим упоминался как существующий.)

## P-4. Счётчик возвратов на закрепление

Ведётся счётчик возвратов на закрепление на связку (Участник + модуль). Жёсткого лимита нет — решение о повторном возврате всегда за Автором. В алерте Автору Бот указывает порядковый номер: «Участник — N-й возврат на закрепление дня X». Счётчик — это сигнал Автору, не автоматика. Заложен как данные (при росте легко превращается в авто-эскалацию одним условием).

## P-5. Трёхтир система уведомлений (утверждено, не парковка)

Три категории:

- **Системные** — обязательные, неотключаемы (пауза, жизни, оплата, блокировки).
- **Напоминания** — регулируемые (в т.ч. лестница «пришёл-не-отправил», дедлайны).
- **Мотивационные** — отключаемые (в т.ч. полуденное уведомление о неактивности).

Участнику даётся экран настроек с чекбоксами, где он включает/выключает каждый тип отключаемого уведомления. Системные в списке не показываются. (Детальный состав экрана настроек — Блок 9 «Коммуникации».)

## P-6. Команда /place — УДАЛЕНА поправкой v3.1

Пункт удалён целиком. Ранее описывал команду ручной установки позиции для миграции тестовых участников; в актуальной архитектуре механика миграции отсутствует, участники начинают путь в боте штатно через онбординг. См. [12-reserve.md](../12-reserve.md).

## YAML — сквозные правила (Приложения)

Единый YAML приложений, перенесён из оригинала (секции `patch_1_global` и `failsafe_registry`) с учётом поправки v3.1 (ключ `P6_place_command` удалён; упоминания `place` в `failsafe_registry` удалены). Тот же блок продублирован в [B-failsafe-registry.md](B-failsafe-registry.md) — оба приложения самодостаточны; при правках YAML синхронизировать обе копии.

```yaml
# ============================================================
# ПРИЛОЖЕНИЯ — сквозные правила (Патч-1) + Fail-safe реестр
# Версия: consolidated v3 + поправка v3.1
# ============================================================

patch_1_global:
  P1_module_numbering: global_sequential      # сквозная нумерация модулей
  P2_author_tz: config_defined                # ТЗ Автора (сводки/график); прочее — ТЗ участника
  P3_night_mode: CANCELLED                     # отменён (Ф-25 / Н-2), бот учитывает ТЗ участника
  P4_return_counter: tracked_soft_limit        # счётчик возвратов, лимит не жёсткий
  P5_notifications_3tier:
    system: non_disablable                     # пауза, жизни, оплата, блокировки
    reminders: adjustable                      # лестница, дедлайны
    motivational: disablable                   # полуденная неактивность
    settings_screen: checkboxes                # детали — Блок 9
  # P6_place_command — УДАЛЁН поправкой v3.1

failsafe_registry:
  irreversible_actions: two_step_confirm       # "Да" не на месте первой кнопки
  reversible_actions: one_tap
  whitelist_only: true
  non_whitelist: [ignore, log]
  command_without_reply: [refuse, ask_reply]
  value_validation: [existing_day_module, life_bounds_0_3]
  life_ops_atomic: true
  race_by_server_time: true
  buttons_idempotent: true
  tz_change: next_day_only
  critical_writes: synchronous_postgres
  pause_not_saving_burning_deadline: true
  fsm_persistent: true
  day_counting: on_confirmed_db_write          # П-31, без ложного успеха
  auto_pass: NEVER
  queue_effect_isolated: true                  # не влияет на зачёт/жизнь
  callback_bound_to: participant_id
  bot_admin_can_delete: required_on_start
  card_access_audit_log: true                  # 152-ФЗ
  no_course_without_legal_texts: true
  append_only_logs: [measurements, reflections, money]
  money_ops_idempotent: true
  no_empty_screens: true                       # П-21
```
