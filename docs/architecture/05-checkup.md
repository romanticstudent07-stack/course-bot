# БЛОК 5. ЧЕК-АП

> **Уточнено ERRATA-UNIFIED.** Конфигурация Чек-Апа, автоскоринг и гейт Legal — патч И3. Тела зон, шапка «Это не медицинский совет», кнопка апелляции, экстренный текст Red Flags — патч И4 (`text_registry`). Отсрочка стирания при активном возврате 14 дн. и retention `refund_details` 3 года — И3. См. [normative/I3-wave-c.md](normative/I3-wave-c.md), [normative/I4-wave-d.md](normative/I4-wave-d.md).

## 5.1. Назначение и место

Диагностический опрос «Уровень системного воспаления» (15 утверждений, шкала 0–3, максимум 45 баллов). Проводится: на старте (Шаг 4.5 онбординга) + после каждого Этапа. Результат = балл + зона + расшифровка. Сохраняется в БД, входит в Карту изменений (Блок 14).

## 5.2. Механика проведения

Вводный текст (что такое системное воспаление) + инструкция по шкале 0–3. Далее по одному вопросу, ответ кнопками [0] [1] [2] [3] (не ручной ввод). Перед вопросами каждого блока — заголовок блока (Блок 1 ЖКТ / Блок 2 Энергия / Блок 3 Когнитивные / Блок 4 Тело). После 15-го вопроса — серверный подсчёт суммы → результат Участнику.

## 5.3. Зоны (границы включительные, жёстко в конфиге)

- 🟢 0–9 — Зелёная (Чистая система).
- 🟡 10–22 — Жёлтая (Сигналы перегрузки).
- 🔴 23–45 — Красная (Системное воспаление).

Тексты расшифровок — в конфиге. Обязательный тест на граничные значения (9, 10, 22, 23).

## 5.4. Показ результата

Участнику — сразу, красивым сообщением: балл + зона + расшифровка. При повторных прохождениях — сравнительное сообщение с прошлым разом: улучшение → хвалим; на месте/хуже → подбадриваем/мотивируем + алерт в тему «Тревожная динамика». Направление трактуем по смыслу (снижение балла = улучшение = прогресс), а не «больше/меньше по числу». Результат падает в группу/карточку.

## 5.5. Хранение

Храним все 15 ответов (не только сумму/зону) + балл + зона + дата. Для аналитики и повторных сравнений. Детальный состав аналитических данных — Блок 14 (приоритетное направление).

## 5.6. Разграничение

Чек-Ап (авто-подсчёт Ботом, Автор не «проверяет» на проход) ≠ Рефлексия дней 6/13-M/13-P (проверяется/модерируется Автором). Не смешивать в коде.

## 5.7. Мед.осторожность

Тексты расшифровок (особенно красной зоны) не должны звучать как мед.диагноз, мягко рекомендуют обращение к врачу при необходимости. Формулировки выверяет юр.блок.

## 5.8. Повторные опросы для Карты изменений

Нужны повторные опросы для Карты изменений по всем её параметрам (включая Чек-Ап) после каждого Этапа. Детальная проработка — Блок 14.

## 🛡 Блок 5 — Fail-safe

Только кнопки 0–3 (никакого ручного ввода баллов). Сохранение прогресса опроса (продолжение с прерванного вопроса). Кнопка «Исправить». Индикатор «Вопрос N из 15». Идемпотентность кнопок. Серверный пересчёт суммы из сохранённых ответов (не доверяем клиенту). Тест граничных значений зон (9/10/22/23). Красная зона не формулируется как диагноз (юр.осторожность).

```yaml
# ============================================================
# БЛОК 5 — Чек-Ап (Уровень системного воспаления)
# Версия: consolidated v3
# ============================================================

checkup:
  title: "Уровень системного воспаления"
  placement:
    - onboarding_step_4_5
    - after_each_stage
  questions: 15
  scale: 0-3                              # только кнопки [0][1][2][3]
  max_score: 45
  blocks:
    - {id: 1, name: "ЖКТ"}
    - {id: 2, name: "Энергия"}
    - {id: 3, name: "Когнитивные"}
    - {id: 4, name: "Тело"}

  intro:
    text: "что такое системное воспаление + инструкция по шкале 0–3"
  flow: question_by_question
  block_header_before_questions: true

  calculation: server_side               # пересчёт из сохранённых ответов
  zones:                                  # границы включительные, хардкод в конфиг
    green:  {range: [0, 9],   label: "Чистая система"}
    yellow: {range: [10, 22], label: "Сигналы перегрузки"}
    red:    {range: [23, 45], label: "Системное воспаление"}
  boundary_tests: [9, 10, 22, 23]        # обязательные тест-кейсы
  zone_texts: config                     # расшифровки в конфиге

  feedback:
    to_participant: instant              # балл + зона + расшифровка, красиво
    on_repeat:
      compare_with_previous: true
      interpret_by_meaning: true         # снижение балла = улучшение
      if_improved: praise
      if_stagnant_or_worse: [motivate, alert_topic_dynamics]
    copy_to: [working_group, participant_card]

  storage:
    keep: [all_15_answers, score, zone, date]   # не только сумму
    purpose: [analytics, repeat_comparison]
    detail: block_14

  distinction:
    checkup: auto_scored_by_bot          # Автор не проверяет на проход
    reflection: moderated_by_author      # дни 6/13 — НЕ смешивать в коде

  medical_caution:
    red_zone_not_diagnosis: true
    soft_recommend_doctor: true
    wording_by: legal_block

  change_map:
    repeat_after_each_stage: all_parameters   # вкл. Чек-Ап
    detail: block_14
```
