# БЛОК 4. ОНБОРДИНГ

> **Переопределено SEAM-PATCH-1 и ERRATA-UNIFIED.** Канонической точкой создания участника (`pid`) объявлен first-launch Mini App (SEAM-1) — не бот-диалог. Блок 4 сохранён как содержание онбординга (согласия, оплата, анкета, Чек-Ап, правила), но не как точка первичной регистрации. Возрастной гейт вынесен перед созданием `pid` (ADD3 ERRATA, `INV-AGE-GATE-BEFORE-PID`). Конвейер согласий C0–C6 и контур поддержки — патч И4 (E2/E3). См. [normative/seam-patch-1-onboarding.md](normative/seam-patch-1-onboarding.md), [normative/I4-wave-d.md](normative/I4-wave-d.md), [normative/errata-unified.md](normative/errata-unified.md).

## 4.1. Последовательность шагов (до старта дня 1.1)

- **Шаг 0** — Приветствие + первичный дисклеймер.
- **Шаг 1** — Согласие на обработку ПДн (152-ФЗ).
- **Шаг 2** — Оферта с согласием: две галочки — «Мне есть 18 лет» + «Согласен с офертой». Кнопка «Подтвердить» неактивна, пока не отмечены обе. Переходит в оплату. (Противопоказания — только общие по физиотерапии, указаны в оферте; отдельного мед.скрининга нет.)
- **Шаг 3** — Оплата первого Этапа → доступ открывается после подтверждения Автором.
- **Шаг 4** — Анкета (ФИО, дата рождения, пол, телефон, часовой пояс, стартовые замеры, фото с 4 сторон, др. поля).
- **Шаг 4.5** — Опрос «Чек-Ап» (см. Блок 5).
- **Шаг 5** — Правила/инструкция + кнопка «Ознакомлен/Принимаю» → старт дня 1.1.

## 4.2. Проверка возраста 18+ (до оплаты)

Галочка «Мне есть 18» в Шаге 2 отсекает несовершеннолетних до оплаты. Точная дата рождения собирается в анкете (Шаг 4); при выявлении < 18 — Бот мягко сообщает о невозможности участия до 18-летия (стык с возвратом — юр.блок / Блок 16).

## 4.3. Тон

Обращение на «Вы».

## 4.4. Механика анкетирования (Вариант C — гибрид)

Пошаговый диалог (по одному вопросу), где можно — кнопки/готовые варианты, где нельзя — короткий ввод.

- ФИО → текст (валидация: не пусто, буквы).
- Дата рождения → текст «ДД.ММ.ГГГГ» (валидация формата + возраст 18+).
- Пол → кнопки.
- Телефон → «Поделиться контактом» (Telegram) или текст (валидация формата). (Сбор телефона текстом без SMS-подтверждения — согласовано.)
- Часовой пояс → кнопки-города.
- Вес / объёмы → число (валидация диапазона).
- Самочувствие → кнопки-шкалы.
- Фото с 4 сторон → по одному (спереди, сзади, два профиля), валидация «это изображение».
- В конце — экран подтверждения: Бот показывает все данные → «Всё верно? [Да] [Исправить]».

## 4.5. UX-принципы онбординга

Обычные кнопки в едином стиле (НЕ крупные). Обязательны «Назад/Исправить». Индикатор прогресса («Шаг/Вопрос N из M»). Дружелюбные примеры форматов при ошибке. Никакого таймера/давления на этапе онбординга. Проход максимально лёгкий, в т.ч. для пожилых. Нет пустых экранов ни на одном шаге (сквозной принцип П-21).

## 4.6. Кнопка «Поддержка» на каждом шаге

На любом шаге онбординга — кнопка «Поддержка/Вопросы». При нажатии: Бот шлёт обращение в тему «Поддержка» Рабочей группы (с кликабельным именем + кнопкой «Карточка») + предлагает Участнику написать вопрос текстом (пересылается в ту же тему).

## 4.7. Заплатил, но не прошёл онбординг (Q-95)

Если оплата подтверждена, но Участник не завершил анкету/Чек-Ап/правила: доступ к дню 1.1 НЕ открывается, Бот шлёт напоминания Участнику + алерт Автору. Доступ только после полного прохождения всех шагов.

## 4.8. Повторный онбординг при рестарте

Исходная анкета (ФИО, дата рождения, регион) НЕ спрашивается заново. При платном рестарте снимаются новые замеры (добавочная запись в журнал замеров, старая неприкосновенна). Чек-Ап проходится заново (новая точка).

## 4.9. Незавершённый онбординг

Прогресс онбординга сохраняется в БД; продолжение с прерванного шага/вопроса.

## 4.10. Согласия и логирование

Каждое согласие (дисклеймер, ПДн, оферта, правила, 18+) фиксируется с датой и временем. Простой явный тап «Принимаю». Хранится для юр.целей (доступно через отдельную команду ⚖️ Юр.данные, НЕ в карточке).

## 4.11. Юр.тексты

Тексты дисклеймера, оферты, правил, формулировка «общих противопоказаний по физиотерапии» — место в конфигурации; сами тексты выверяет юр.блок. Fail-safe: курс не запускается без заполненных юр.текстов.

## 4.12. Оферта покрывает все Этапы

Акцепт оферты при онбординге покрывает все последующие Этапы — повторный акцепт на каждом Рубеже (13-P) не требуется, сам факт оплаты Этапа = принятие условий (стык с Блоком 16). Финальный текст оферты (особенно раздел возвратов и оговорка о возможной смене цены) — юр.блок.

## 🛡 Блок 4 — Fail-safe

Валидация всех полей + дружелюбный переспрос с примером. Сохранение прогресса онбординга в БД (продолжение с прерванного шага). Логирование всех согласий с датой/временем. Фильтр 18+ до оплаты (галочка) + жёсткая проверка по дате рождения в анкете. Идемпотентность кнопок согласия. Экран подтверждения данных перед фиксацией. Неприкосновенность первой записи журнала замеров. Блокировка старта дня 1.1 без полностью пройденного онбординга (Q-95). Блокировка запуска курса без заполненных юр.текстов. Нет пустых экранов (П-21).

## YAML — онбординг (Блок 4)

```yaml
# ============================================================
# БЛОК 4 — Онбординг
# Версия: consolidated v3
# ============================================================

onboarding:
  no_empty_screens: true                  # П-21
  support_button: everywhere              # на каждом шаге
  tone: formal_vy                         # обращение на «Вы»
  progress_persistence: true             # сохранение шага, retry-on-error
  no_timer_pressure: true                # без давления на онбординге
  button_style: uniform_not_large

  steps:
    step_0: greeting_plus_disclaimer
    step_1: legal_152fz_consent
    step_2:
      offer: true
      age_gate: 18plus
      contraindications: general_physiotherapy   # только в оферте, отд. скрининга нет
      checkboxes_before_activation: [age_18plus, offer_consent]
      confirm_button_enabled_when: both_checked
      next: payment
    step_3:
      payment: true                       # оплата ДО анкеты; доступ после подтв. Автора
      detail: block_16
    step_4:
      questionnaire: hybrid_option_C      # кнопки + текст + Telegram contact share
      fields:
        name_surname: {input: text, validate: [not_empty, letters]}
        birthdate:    {input: text, format: "ДД.ММ.ГГГГ", validate: [format, age_18plus]}
        gender:       {input: buttons}
        phone:        {input: [telegram_contact_share, text], validate: format}
                      # текст без SMS-подтверждения — согласовано
        timezone:     {input: city_buttons}
        measurements: {input: number, validate: range, storage: append_only}
        wellbeing:    {input: scale_buttons}
        photos_4_sides: {input: one_by_one,
                         angles: [front, back, profile_L, profile_R],
                         validate: is_image}
      confirm_screen: "Всё верно? [Да] [Исправить]"
    step_4_5:
      checkup: true                       # см. Блок 5
    step_5:
      rules_consent: true
      button: "Ознакомлен/Принимаю"
      then: start_day_1_1

  age_check:
    pre_payment: checkbox_18plus
    hard_check: birthdate_in_questionnaire
    if_under_18: [gentle_block, refund_stitch_block_16_legal]

  consent_logging:
    fields: [timestamp, consent_text]
    immutable: true
    access_via: command_legal_data        # ⚖️ Юр.данные (НЕ в карточке)

  edit_rules:
    name_surname: editable_via_author
    timezone: applies_next_day            # 3.21
    measurements: append_only             # 2.9
    birthdate: locked

  paid_but_incomplete:                    # Q-95
    action: [no_access_until_complete, remind_participant, alert_author]

  restart_onboarding:                     # 4.8
    reask: none                           # ФИО/дата/регион не спрашиваем заново
    new_measurements: append_to_journal   # старая запись неприкосновенна
    checkup: retake_new_point

  legal_texts:
    location: config
    verified_by: legal_block
    failsafe: course_locked_without_texts

  offer:
    covers_all_stages: true               # повторный акцепт не нужен
    payment_equals_acceptance: true
    final_text: by_lawyer                 # раздел возвратов + оговорка о цене
```
