## Выжимка

D1 закрывает транспортную половину дерева «Пройденного»: «Назад» обязателен на каждом уровне, вычисляется резолвером как логический родитель (Б10-Ш5 Р100), edit-in-place «одно окно», `back_must_show_visible_change`. Структура дерева (Этап→Модуль→День + правила узлов) — владение Б13-Ш3, D1 её только наследует. Направление «Назад» = инверсия канонической структуры Б13.

## Ключевые решения

Р-D1.1 — разграничение: дерево (структура/узлы) = Б13; «Назад» (транспорт) = Б10. D1 = только транспорт. Р-D1.2 — направление: каноническая структура Этап→Модуль→День (сверху вниз); «Назад» = инверсия День→Модуль→Этап→корень. НЕ переопределяет дерево. Р-D1.3 — «Назад» = резолвер логического родителя от актуального состояния (Р100/Р61), НЕ message-stack; при обрезке узла (V48) → фоллбэк (V50). Р-D1.4 — навигация бесплатна (уровни/Назад лимит не жгут); списывается только лист-День (`b13_quota_charge`, Б13-Ш3). Р-D1.5 (Скептик) — корень = терминал Назад с видимой реакцией («ты в корне»), анти-тупик (`back_must_show_visible_change`, П-21).
