## Р-решения
- Р-1 (17.10) — оплата. Делаем: оплаты в Mini App нет совсем (onb.payment, payment.* не делать); оплата — в личке с Автором. В каноне устарело: build-order И4, miniapp-screens onb.payment, payment.* — внесено DOCS #15 → #137. Источник: R-2026-10-1.md.

Дополнение 23.10 (api-access-1): first-launch при отсутствии активного участника и access_grants.status ≠ granted → 403 ACCESS_NOT_GRANTED, pid не создаётся; GET /onboarding/status → 200 {"status":"no_access"}. Перекрывает запрет «403 для неизвестного tg_user_id» (D-9 п.2, R327). Существующих участников гейт не трогает. В каноне устарело: нет команды Панели для доступа и экрана «доступ не открыт» (D-39); гейт lifecycle.start; 04 §4.7 Q-95; D-9 п.2, R327. Источник: R-2026-10-1.md.
- Р-3 (17.10) — фото. Делаем: фото участников нет: C5, слой «фото» Карты, /view_photos, /grant_photos_access, photo_view_log, S3_BUCKET_PHOTOS — не делать. В каноне устарело: И4, Refund Saga — внесено DOCS #15 → #137; файлы с оплатой — врезка «Р-4: на потом» (окно 1б). Источник: R-2026-10-1.md.
