## 2. Цель
Скрипт tools/build_cities.py скачивает открытый справочник городов РФ (закреплён по commit), переводит пояс «UTC+N» в IANA и пишет apps/api/config/onboarding/cities.csv (city, region, tz). Файл генерирует Автор в Codespaces; КОДЕР, Агент и чаты список по памяти не пишут и не правят. Тест проверяет данные.

## 3. Решения (метки К-6)
- Р-16 [Автор, DECISIONS]: «город → только tz (IANA), сам город не храним».
- Р-17 [Автор 07.11; запись в DECISIONS — docs-пакетом ШТАБа]: город — поле ввода, подсказки с 2 введённых букв (до 10), рядом с городом — область; засчитывается только выбор из подсказок; список ≈1 100 городов РФ с IANA-поясом; кнопка «Моего города нет» → текст-заглушка → 11 кнопок, по одному городу на каждый пояс РФ.
- Ш-5 [ШТАБ-тех 07.11, К-5]: файл — скриптом tools/…, запускает Автор; проверки в тестах: все tz открываются ZoneInfo; все 11 поясов РФ; в Якутии ≥ 2 пояса; нет дублей (city, region).
- Ц-1 [ПРОЕКТИРОВЩИК, К-5; утверждено ШТАБом 07.11]: источник — github.com/hflabs/city (DaData.ru), лицензия CC BY-SA 4.0, commit ae661bffe572880472249097c9b29c42b09650ea («Данные от 11.10.2021»); ≈1 117 городов из списка Википедии. Поле timezone там — строка «UTC+N», не IANA.
- Ц-2 [ПРОЕКТИРОВЩИК, К-5; утверждено ШТАБом 07.11]: «UTC+N» → один IANA-пояс на смещение (§7), не по координатам (timezonefinder — лишняя зависимость, данные ODbL); для границ суток важен только текущий сдвиг, летнего времени в РФ нет. Итог: в файле ровно 11 IANA-поясов — тот же набор, что 11 запасных кнопок api-i3-2.

## 7. Скрипт tools/build_cities.py (только stdlib)
- Константы SOURCE_COMMIT и SOURCE_URL = https://raw.githubusercontent.com/hflabs/city/ae661bffe572880472249097c9b29c42b09650ea/city.csv. Флаг --input <файл> — локальная копия без сети. Таймаут 30 с; ошибка сети → код 1 и понятный текст.
- Печатает sha256 исходника и число строк (Автор вписывает sha256 в CITIES-SOURCE.md).
- OFFSET_TO_TZ, ровно 11: UTC+2 Europe/Kaliningrad; UTC+3 Europe/Moscow; UTC+4 Europe/Samara; UTC+5 Asia/Yekaterinburg; UTC+6 Asia/Omsk; UTC+7 Asia/Novosibirsk; UTC+8 Asia/Irkutsk; UTC+9 Asia/Yakutsk; UTC+10 Asia/Vladivostok; UTC+11 Asia/Magadan; UTC+12 Asia/Kamchatka. Другое смещение → код 1 со списком строк.
- city = поле city; пустое и region_type «г» → city = region; пустое в остальных случаях → код 1.
- region для показа: обл → «{r} область»; край → «{r} край»; Респ → «Республика {r}»; АО → «{r} автономный округ»; Аобл → «{r} автономная область»; г → «{r}». Другой region_type → код 1 со списком. Прочие поля источника (координаты, коды, население) не пишутся.
- Дубль (city, region) → код 1 со списком. Сортировка по (city, region). UTF-8, LF (lineterminator="\n"), заголовок city,region,tz.
- Без аргументов пишет apps/api/config/onboarding/cities.csv от корня репо (git rev-parse или путь от файла скрипта). Итог: «cities.csv: N строк, поясов 11», код 0.

## 9. Тесты — apps/api/tests/test_cities_data.py (без БД; tools/check.sh api и CI)
1. Заголовок ровно city,region,tz; пустых полей нет; строк 1 000–1 300.
2. Каждый tz открывается ZoneInfo.
3. Набор tz равен 11 значениям из §7 (список из 11 — в самом тесте).
4. Строки, где region содержит «Якути»: ≥ 2 разных tz.
5. Дублей (city, region) нет.
6. Москва → Europe/Moscow; Калининград → Europe/Kaliningrad; Петропавловск-Камчатский → Asia/Kamchatka.
