## 7. Контракт
- GET /miniapp/v1/consents: pid по tg_user_id из initData (активная строка). Нет участника → 200 [].
  Для каждого kind — последнее событие: given_at (give), revoked_at (revoke или null), legal_status из text_registry.
  503 при БД. Записи согласий (give/revoke) здесь НЕТ (отзыв C5 — сага стирания, поздняя итерация).
- Экраны после «готово» из 1e-1: offer (legal.offer, кнопка «Далее», в журнал не пишет) →
  email (необязательное поле, «Пропустить») → city (кнопки-города) → checkup (B4.onb_checkup) →
  rules (B4.onb_rules, «Ознакомлен» → экран-заглушка). На каждом — «Назад» и «Шаг N из M».
  На сервер ничего не отправлять: эндпоинта анкеты нет — только черновик.
- drafts.ts: нативный IndexedDB без библиотек, за интерфейсом DraftStore (тест — хранилище в памяти).
  Черновик привязан к tg_user_id; другой tg_user_id → полная очистка сразу; черновик старше 24 ч → удалить
  при открытии. Дату рождения туда не класть никогда.
