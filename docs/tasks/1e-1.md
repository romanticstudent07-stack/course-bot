  legal.consent_c0_age_18_plus, legal.consent_c1_pdn.
- onboarding.py: REQUIRED_AT_FIRST_LAUNCH = {"C0", "C1"}; CONSENT_TEXT_KEYS = {C0: legal.consent_c0_age_18_plus,
  C1: legal.consent_c1_pdn}. Текст выбирает СЕРВЕР, клиент шлёт только id.
- POST /miniapp/v1/onboarding/first-launch, тело {birth_date: date, consents: ["C0", "C1"]}. Порядок (не менять!):
  1) initData (роутер) → 2) тело (Pydantic; дубли или id вне C0–C6 → 422) → 3) возраст БЕЗ БД → 403 (как сейчас)
  → 4) REQUIRED ⊆ consents, иначе 422 CONSENTS_REQUIRED {details: {missing: [...]}} → 5) ОДНА транзакция:
  прочитать тексты из text_registry (нет текста → откат, 503 SERVICE_MISCONFIGURED) → get_or_create участника →
  INSERT consent_events для каждого присланного kind, у которого у pid ещё нет give (action give,
  ver_of_text = registry_version, text_snapshot = текст) → commit.
  Ответ 201 {pid, short_no}; повтор → 201 тот же pid, без дублей; БД недоступна → 503 как сейчас.
- ip и ua в И1 не заполняются (NULL): за туннелем IP недостоверен, --proxy-headers — к проду.
- Mini App: welcome (B4.onb_welcome) → age-gate (B4.onb_age_gate: галочка C0 + поле даты; дата только в памяти,
  не в IndexedDB/localStorage) → consent (legal.onb_consent_intro + галочка C1; галочки выключены, кнопка неактивна
  до всех обязательных, остальной UI недоступен) → POST first-launch → B4.onb_done.
  403 → B4.onb_age_underage (дружелюбно; повтор — открыть Mini App заново, Р47); 422 → назад на consent.
  Тексты — одним POST /texts/bulk; initData — сырой строкой в X-Telegram-Init-Data (initDataUnsafe нельзя).

## 8. БД — миграция 0004_consent_events
consent_events: id bigserial PK; pid uuid NOT NULL REFERENCES tg_user_registry(pid);
kind text NOT NULL CHECK IN ('C0','C1','C2','C3','C4','C5','C6'); action text NOT NULL CHECK IN ('give','revoke');
at timestamptz NOT NULL DEFAULT now(); ip inet NULL; ua text NULL; ver_of_text text NOT NULL;
text_key text NOT NULL REFERENCES text_registry(key); text_snapshot text NOT NULL;
created_via text NOT NULL CHECK IN ('mini_app_first_launch'). INDEX consent_events_pid_kind_at_idx (pid, kind, at).
Append-only (UPDATE/DELETE запрещаются через GRANT в B-3). downgrade: DROP TABLE IF EXISTS consent_events.
