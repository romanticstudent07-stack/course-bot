## 2. Цель
Сейчас «Перейти к курсу» не трогает черновик: email и город лежат на устройстве до TTL 24 ч.
После правки в черновике остаётся только `{step: 'finished', email: '', city: ''}` — без ПДн,
и при следующем открытии участник сразу видит экран finished. Ошибка хранилища переход не блокирует.

  ошибка clear переход не блокирует.» Уточнено ответом 5:
- «Б — на finished стирать email и city, оставить {step:'finished'}. Тест: peek() — step 'finished',
  email '', city ''; clear упал/put упал → onFinish всё равно 1 раз. Живая проверка: дойти до
  «Перейти к курсу», закрыть/открыть → после онбординга сразу экран finished, город не сохранён.»
- ШТАБ: «readTgUserId на клиенте — оставить как есть.»

## 7. Контракт (функции)
drafts.ts — добавить:
    /** Черновик после «Перейти к курсу»: только метка шага, без email и города. */
    export const FINISHED_DRAFT: Draft = { step: 'finished', email: '', city: '' };

    export async function finishDraft(
      store: DraftStore, tgUserId: number | null, now: number, onFinish: () => void,
    ): Promise<void>
Поведение finishDraft:
- tgUserId !== null → `saveDraft(store, tgUserId, FINISHED_DRAFT, now)`;
  tgUserId === null → `store.clear()` (пользователь неизвестен — ничего не храним);
- запись в try/catch: reject и синхронный throw хранилища глотаются, в лог ничего;
- затем `onFinish()` ровно 1 раз, после попытки записи; finishDraft из-за хранилища не reject-ится;
- ошибка внутри самого onFinish не перехватывается (второго вызова нет).
- В шапку drafts.ts добавить правило: «Перейти к курсу» → в черновике только `{step: 'finished'}`.
LaterSteps.tsx:
- контейнер `LaterSteps` передаёт во `LaterStepView` новый обработчик:
      onFinish={() => { void finishDraft(store, tgUserId, Date.now(), onFinish); }}
  импорт `finishDraft` из './drafts.ts'. `LaterStepView`, `LaterStepsProps`, редьюсер — без правок;
- в шапке-комментарии одна строка: «Перейти к курсу» → в черновике только метка finished (finishDraft).
Эффект автосохранения не трогать. При следующем открытии `openDraft` вернёт `{step:'finished'}` → экран finished.

## 9. Тесты (vitest, environment node; drafts.test.ts, новый describe «finishDraft»)
Счётчик: `let calls = 0; const onFinish = () => { calls += 1; };`. Сбойные хранилища — объект
`DraftStore`, как в существующем тесте с `cleared`.
1. Сохранён DRAFT (city + email) → finishDraft(USER) → `peek()` toEqual
   `{ v: 1, tgUserId: USER, savedAt: NOW, step: 'finished', email: '', city: '' }`; calls === 1.
2. После п.1 `openDraft(store, USER, NOW + 1000)` → `{ step: 'finished', email: '', city: '' }`.
3. put возвращает reject → finishDraft резолвится; calls === 1.
4. put бросает синхронно (обычная функция с throw) → calls === 1.
5. tgUserId === null → clear вызван, put не вызван; calls === 1.
6. tgUserId === null и clear возвращает reject → calls === 1.
Существующие тесты (в т.ч. сканирование LaterSteps.tsx в OnboardingFlow.test.ts) — зелёные.
